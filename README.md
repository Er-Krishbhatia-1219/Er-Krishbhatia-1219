### ⚡ Electricity Demand Forecasting with XGBoost

**Python | Pandas | XGBoost | Scikit-learn | Time-Series | EDA**

An end-to-end machine learning project for forecasting electricity demand at five-minute intervals.

**Key Work:**
- Exploratory Data Analysis
- Time-based feature engineering
- Calendar feature creation
- Lag and autoregressive features
- Chronological train-test split
- XGBoost regression
- Model evaluation using MAE and RMSE

**Model Performance:**
- MAE: **42.32**
- RMSE: **117.79**
